# Claude Usage

Open this folder as the project root in Claude Code or another Claude-based local coding agent.

Claude should read `CLAUDE.md` as the project-level instruction file. If a continuing or older conversation seems confused, paste:

```text
Please reread CLAUDE.md, README.md, and TASKS.md. Continue in the existing task folder if this is the same topic. Do not create a new timestamp folder unless this is a new task.
```

For a new task, ask normally. Claude should create or reuse a task folder under `01_tasks/`.
