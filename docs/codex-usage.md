# Codex Usage

Open this folder as the workspace root in Codex.

Codex should read `AGENTS.md` automatically as the project-level instruction file. If a continuing or older conversation seems confused, paste:

```text
Please reread AGENTS.md, README.md, and TASKS.md. Continue in the existing task folder if this is the same topic. Do not create a new timestamp folder unless this is a new task.
```

For a new task, ask normally. Codex should create or reuse a task folder under `01_tasks/`.
