# agent-workspace-playbook

A local workspace standard for multi-agent experiments and workflows.
一个用于管理多 Agent 实验与工作流的本地工作空间标准。

**English** → [README.en.md](README.en.md) · **中文** → [README.zh-CN.md](README.zh-CN.md)

This Playbook provides a structured method for managing AI-agent-driven local workspaces: keeping the workspace structure clear, managing experiments, preserving important context, reusing effective workflows, and staying consistent across different machines.

本 Playbook 提供一套结构化方法，用于管理 AI Agent 驱动的本地工作环境：保持 Workspace 结构清晰、管理实验过程、保存重要上下文、复用有效 Workflow，并在不同设备之间保持一致。

## 核心规则 / Core Rules

| 中文 | English |
|---|---|
| 每个新任务使用独立目录 `01_tasks/YYYY-MM-DD-HHMM-short-task-name/`。 | Each new task uses its own directory `01_tasks/YYYY-MM-DD-HHMM-short-task-name/`. |
| 所有产出默认留在当前工作区；不写入全局 `.codex`、`.claude`、`.agents` 或系统目录。 | All outputs stay inside the current workspace by default; do not write to global `.codex`, `.claude`, `.agents`, or system directories. |
| 单 Agent 工作区只保留当前 Agent 的规则文件；多 Agent 共用工作区同时保留 `AGENTS.md` 与 `CLAUDE.md`。 | A single-agent workspace keeps only its own rule file; a multi-agent workspace keeps both `AGENTS.md` and `CLAUDE.md`. |
| `INDEX.md` 由 `scripts/build_index.py` 自动生成，不需要人工维护。 | `INDEX.md` is generated by `scripts/build_index.py`; do not maintain it by hand. |
