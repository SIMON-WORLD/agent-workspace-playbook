# TASKS.md

Register every new task here.

Task directory naming format:

```text
01_tasks/YYYY-MM-DD-HHMM-short-task-name/
```

Continue the same topic in the same task directory. Do not create a new timestamp folder for follow-up questions, restarts, verification, fixes, or documentation updates.

New task folders should use:

```text
prompt.md
notes.md
01_assets/
02_output/
03_logs/
04_tmp/
```
